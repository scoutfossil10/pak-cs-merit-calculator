
# 🎓 Pakistani CS Merit & Target Score Calculator

A live Python & Streamlit web application built for **FBISE** and **BISE Lahore** FSc/ICS students applying to Pakistani Computer Science and Engineering universities (**NUST, FAST-NUCES, COMSATS, ITU, UET Lahore, and GIKI**).

🔗 **Live App:** https://pak-cs-merit.streamlit.app/

### Features
- **Forward Aggregate Calculator:** Computes exact merit percentages using each university's official Matric, Inter Part-1, and Entry Test weightages.
- **Reverse Target Score Solver:** Algebraically calculates the exact minimum marks required on NET, NU Test, NAT, ECAT, and GIKI tests to reach a target closing merit, including edge-case checks.
